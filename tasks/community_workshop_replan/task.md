# Community Workshop Room Replan

You are helping finalize room assignments for three community workshops at Bayview Civic Center.

Read the local planning files in this folder. Create the deliverables listed in `output_contract.md` inside an `answer/` folder in this task folder.

Work in two stages:

1. Use the initial planning files to create `answer/initial_room_plan.md`.
2. If a coordinator update is introduced during the work, use it to create `answer/update_response.md` and `answer/final_room_plan.md`.

The top-level objective stays the same throughout: leave behind a room assignment package for all three sessions. Use local files only.
