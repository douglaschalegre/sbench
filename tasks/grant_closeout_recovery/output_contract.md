# Deliverable Contract

Create an `answer/` folder in this task folder, then create these three files inside it. Markdown tables or concise labeled sections are fine, but the paths, filenames, and required facts must be present.

## `answer/audit_findings.md`

Audit the prior work before presenting corrected decisions.

Required facts:

- Which prior facts or decisions should be preserved.
- Which prior facts or decisions should be corrected.
- Which expense, if any, was omitted from the prior draft.
- Which award cap source controls and why.
- Local evidence file names supporting preservation and correction decisions.

## `answer/corrected_expense_decisions.md`

Write the corrected expense decision table.

Required facts:

- One row or entry for every expense ID in `04_expenses.csv`.
- For each expense: requested amount, approved amount, approve/reject/partial decision, and reason.
- The volunteer refreshments cap when applied.
- The receipt rule when applied.
- The corrected reimbursable total.

## `answer/final_closeout_summary.md`

Write the final closeout summary for the program manager.

Required facts:

- Correct award cap and source.
- Correct reimbursable total.
- Remaining amount under the cap.
- Preserved useful prior work.
- Corrected wrong prior work.
- Outcome facts from the local outcome note.

Rules:

- Use local files only.
- Do not put the required deliverables in the task root; put them under `answer/`.
- Preserve correct prior work when it is supported by the current local evidence.
- Extra scratch files are allowed, but the three named deliverables under `answer/` are the review packet.
