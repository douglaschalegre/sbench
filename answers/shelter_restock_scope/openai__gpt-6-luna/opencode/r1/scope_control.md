# Scope Control — Phase 1 Purchase Packet

## Core objective

Select approved Phase 1 North Shelter restock supplies that fit within the $2,200.00 budget and can arrive by each item's need-by date for the 2026-07-01 opening.

## Inclusion rule

Include a request only if it is Phase 1, approved, in the medical/shelter/power/water categories, deliverable by its need-by date from the preferred vendor, and the combined selection stays within budget. All eligible items are included when they fit the budget.

## Secondary requests

| Request | Disposition | Scope note |
|---|---|---|
| Communications slogan and logo welcome banner layout | Out of scope | Communications/design work is not a Phase 1 restock purchase. The banner request R-104 is excluded from the purchase list. |
| Volunteer shelter-intake training agenda | Deferred | Training is outside this purchase packet and remains for separate follow-up. |
| Drone batteries for August documentation | Deferred | August media equipment is not part of the approved Phase 1 restock; related request R-105 is excluded. |
| Phase-two south-entrance signage plan | Deferred | Phase-two planning is outside the current packet. |

Out-of-scope and deferred requests were not completed as part of the restock packet; no banner design, training agenda, media purchase decision, or phase-two signage plan is included here.
