# Scope Control

Core objective: select approved Phase 1 North Shelter restock items that fit the current $2,200.00 budget and can arrive by each item's need-by date.

Rule used to keep requests in or out of scope: include a supply request only when all of the following are true: it is Phase 1, request status is approved, category is medical, shelter, power, or water, the preferred vendor can deliver by the need-by date, and including it keeps the selected total within budget.

Secondary request disposition:

| Secondary Request | Disposition | Reason |
| --- | --- | --- |
| Slogan and layout for a logo welcome banner | out of scope | Communications work is explicitly outside the Phase 1 restock purchase packet. |
| Draft training agenda for shelter intake volunteers | defer | Training support is not part of the current supply restock packet. |
| Whether to buy drone batteries for August documentation work | out of scope | Media equipment is explicitly outside this packet, and the related supply request is also Phase 2. |
| Phase-two signage plan for the south entrance | out of scope | Phase-two planning is explicitly outside the current Phase 1 restock packet. |

Out-of-scope requests were not completed as part of the restock packet.
