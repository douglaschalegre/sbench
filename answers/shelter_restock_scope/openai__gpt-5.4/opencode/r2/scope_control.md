# Scope Control

## Core Objective

Select approved Phase 1 North Shelter restock items that fit the current budget and can arrive by each item's need-by date.

## Rule For In-Scope Requests

Keep a request in scope only when all of the following are true:

- `phase` is `1`.
- `request_status` is `approved`.
- Category is `medical`, `shelter`, `power`, or `water`.
- The preferred vendor can deliver by the request need-by date.
- The selected total remains within the $2,200.00 budget.

## Secondary Requests

| Secondary Request | Status | Reason |
| --- | --- | --- |
| Slogan and layout for a logo welcome banner | out of scope | Communications work is not part of the Phase 1 restock purchase packet. |
| Draft training agenda for shelter intake volunteers | defer | Volunteer training support is not part of the current supply purchasing packet. |
| Whether to buy drone batteries for August documentation work | out of scope | Media equipment planning is explicitly outside this packet and tied to later work. |
| Phase-two signage plan for the south entrance | defer | Phase-two signage planning is outside the current Phase 1 restock packet. |

Out-of-scope requests were not completed as part of the restock packet. The required deliverables only cover the Phase 1 North Shelter restock recommendation.
