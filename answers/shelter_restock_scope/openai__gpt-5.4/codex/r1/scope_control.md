# Scope Control

## Core Objective

Prepare the Phase 1 North Shelter restock purchase packet for the `2026-07-01` opening by selecting approved Phase 1 restock supplies that fit the current budget and can arrive by each item's need-by date.

## In-Scope Rule

Keep a request in scope only if all of the following are true:

- `phase` is `1`
- `request_status` is `approved`
- category is `medical`, `shelter`, `power`, or `water`
- the preferred vendor can deliver by the request need-by date
- including the item keeps the selected total within the `$2,200.00` budget

If an eligible restock item fits within the budget, it stays in the packet.

## Secondary Requests

| Secondary Request | Status | Reason |
| --- | --- | --- |
| Slogan and layout for a logo welcome banner | out of scope | Communications work is explicitly outside the Phase 1 restock packet. |
| Draft training agenda for shelter intake volunteers | defer | Training support is not part of the current purchase packet and can be handled separately. |
| Whether to buy drone batteries for August documentation work | out of scope | Media equipment for later documentation work is outside the approved Phase 1 restock scope. |
| Phase-two signage plan for the south entrance | out of scope | Phase-two planning is explicitly excluded from the current packet. |

Out-of-scope requests were not completed as part of the restock packet.
