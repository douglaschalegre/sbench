# Scope Control

## Core Objective

Prepare the Phase 1 North Shelter restock purchase packet by selecting approved Phase 1 shelter restock items that fit the current budget and can arrive by each item's need-by date.

## Scope Rule

Keep a request in scope only if all of the following are true:

- `phase` is `1`
- `request_status` is `approved`
- category is `medical`, `shelter`, `power`, or `water`
- the preferred vendor can deliver by the request need-by date
- the selected total remains within the `$2,200.00` budget

## Secondary Request Disposition

| Secondary request | Status | Reason |
| --- | --- | --- |
| Communications request for a slogan and layout for a logo welcome banner | out of scope | Communications design work is explicitly outside the Phase 1 restock purchase packet. |
| Volunteer coordinator request for a draft training agenda for shelter intake volunteers | out of scope | Training materials are explicitly outside the current restock packet. |
| Field media request on buying drone batteries for August documentation work | defer | This is future media work for August and not part of approved Phase 1 restock purchasing. |
| Facilities request for a phase-two signage plan for the south entrance | defer | Phase-two planning is not part of the current Phase 1 restock packet. |

Out-of-scope requests were not completed as part of the restock packet.
