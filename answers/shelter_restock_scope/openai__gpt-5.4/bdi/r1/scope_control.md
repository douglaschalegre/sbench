# Scope Control

## Core Objective
Prepare the Phase 1 North Shelter restock purchase packet using local task files only, limited to approved Phase 1 restock supplies for the North Shelter.

## In-Scope / Out-of-Scope Rule
A supply request is included only if all of the following are true:

- `phase` = `1`
- `request_status` = `approved`
- `category` is one of `medical`, `shelter`, `power`, or `water`
- Preferred vendor can deliver by the request need-by date
- The selected total remains within the `$2,200.00` budget

Additional control rule: if all eligible restock items fit within budget, include all eligible restock items.

Requests outside those rules, plus secondary communications, training, media, and phase-two planning work, are kept out of the packet.

## Secondary Requests Status

| Secondary Request | Status | Scope Note |
|---|---|---|
| Slogan and layout for a logo welcome banner | Out of scope | Communications work is not part of the Phase 1 restock purchase packet. |
| Draft training agenda for shelter intake volunteers | Deferred | Training support is not part of the current restock packet. |
| Whether to buy drone batteries for August documentation work | Out of scope | Media equipment for August documentation work is outside Phase 1 approved restock scope. |
| Phase-two signage plan for the south entrance | Out of scope | Phase-two planning is explicitly outside the current packet. |

## Note
Out-of-scope and deferred requests were documented here but were **not completed** as part of the restock packet.
