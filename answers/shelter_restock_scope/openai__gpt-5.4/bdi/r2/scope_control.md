# Scope Control

## Core objective

Prepare the **Phase 1 North Shelter restock purchase packet** for approved supply purchases only.

## Scope rule

A request is included in the core packet only when all of the following are true:

- `phase` = `1`
- `request_status` = `approved`
- category is one of `medical`, `shelter`, `power`, or `water`
- preferred vendor can deliver by the request `need_by` date
- the selected total remains within the **$2,200.00** budget

If eligible restock items fit within the budget, all eligible restock items are included.

## Request boundary notes

- **Included core restock requests:** R-101, R-102, R-103, R-106
- **Excluded supply requests:**
  - **R-104** — out of scope because it is a communications request
  - **R-105** — out of scope because it is phase 2, not approved, and media-related

## Secondary requests status

| Secondary request | Status | Reason |
|---|---|---|
| Slogan and layout for a logo welcome banner | Out of scope | Communications work is not part of the Phase 1 restock purchase packet. |
| Draft training agenda for shelter intake volunteers | Deferred / out of scope | Training work is not part of approved Phase 1 restock supplies. |
| Buy drone batteries for August documentation work | Out of scope | Media equipment is outside this packet; related supply request is also phase 2 and not approved. |
| Phase-two signage plan for the south entrance | Deferred / out of scope | Phase-two planning is explicitly outside the current Phase 1 packet. |

## Control note

Out-of-scope and deferred requests were **recorded only** and were **not completed as part of the restock packet**.
