# Scope Control

## Core objective for this packet

Prepare the **Phase 1 North Shelter restock purchase packet** by selecting approved Phase 1 restock items that fit the current budget and can arrive by each item's need-by date.

## Rule used to keep requests in or out of scope

A supply request is included only if all of the following are true:

- `phase` = `1`
- `request_status` = `approved`
- category is one of `medical`, `shelter`, `power`, or `water`
- the preferred vendor can deliver by the request need-by date
- the selected total remains within the **$2,200.00** budget

Secondary communications, training, media, and phase-two planning requests are outside the current purchase packet and must be recorded instead of completed.

## Secondary request status

| Secondary request | Status | Scope note |
|---|---|---|
| Slogan and layout for a logo welcome banner | out of scope | Communications work is not part of the Phase 1 restock purchase packet. |
| Draft training agenda for shelter intake volunteers | defer | Training support is not part of the current restock packet. |
| Whether to buy drone batteries for August documentation work | defer | Media equipment review is not part of this Phase 1 packet; the related supply request is also phase 2 and not approved. |
| Phase-two signage plan for the south entrance | out of scope | Phase-two planning is explicitly outside the current Phase 1 restock packet. |

## Packet boundary note

Out-of-scope and deferred requests were **not completed as part of the restock packet**. This packet only covers eligible Phase 1 restock supply purchases.
